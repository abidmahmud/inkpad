Inkpad — install as an app on your tablet (optional)

Inkpad.html already works on its own: copy it to the tablet and open it in Chrome
or Samsung Internet. Hosting this folder on the web turns it into an installable
app that runs full-screen and offline, with the most reliable storage.

1. Put the files of this folder on any static host, for example:
   - GitHub Pages: new repository → upload these files → Settings → Pages →
     "Deploy from branch" (main, root). Your link: https://<user>.github.io/<repo>/
   - Netlify Drop: open app.netlify.com/drop and drag this folder onto the page.
2. Open the link on the tablet in Chrome.
3. Chrome menu (⋮) → "Install app" / "Add to home screen".

Notes are stored per browser and per address. Notebooks made in the file version
do not appear in the hosted version automatically: in the old one use
Library → ⋯ → "Back up all notebooks", then in the new one "Restore a backup".
